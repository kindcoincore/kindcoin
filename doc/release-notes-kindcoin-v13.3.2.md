# Kindcoin Core v13.3.2

Kindcoin Core v13.3.2 is a visual maintenance release that brings the desktop
wallet, packaged applications, and public repository in line with the current
Kindcoin identity.

## Release Summary

| | v13.3.2 |
| --- | --- |
| Update type | Branding and maintenance |
| Network compatibility | Compatible with v13.3.1 |
| Reindex required | No |
| Wallet migration required | No |
| Consensus changes | None |

## What Changed

- Updated desktop application and taskbar icons.
- Updated Windows installer and packaged application artwork.
- Updated repository branding and project information.
- Release downloads include a checksummed branding pack with transparent avatar
  and emblem sizes for exchanges, mining pools, bots, and community services.
- Updated copyright metadata for 2026.

## Upgrade

1. Close the previous Kindcoin Core wallet cleanly.
2. Keep a secure backup of `wallet.dat`.
3. Replace the previous application files with the v13.3.2 package for your
   platform.
4. Start Kindcoin Core normally.

No reindex or wallet migration is required. This release does not change
consensus rules, the network protocol, staking rewards, addresses, or wallet
files.

## Verify Downloads

Compare downloaded packages with `SHA256SUMS.txt` from the same GitHub release
before installing or distributing them.

The branding archive contains its own `SHA256SUMS.txt` for verifying individual
artwork files.
